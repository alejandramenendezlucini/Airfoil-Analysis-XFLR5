# Airfoil Analysis Using XFLR5

Computational aerodynamic analysis of four NACA 6-series laminar-flow airfoils (NACA 63A006, NACA 63009, NACA 631012, and NACA 633018) evaluated at $Re = 5.8 \times 10^6$ and $M = 0.17$. This study compares potential-flow coupled boundary layer predictions from **XFLR5** against experimental wind tunnel data from **NACA Technical Note 2502**.

## Key Features & Analyses
* **Pressure Coefficient Distributions ($C_p(x/c)$)**: Analysis of leading-edge suction peaks, boundary layer behavior, and pressure recovery trends across different thickness ratios.
* **Lift Curves ($C_l(\alpha)$)**: Evaluation of lift curve slopes, maximum lift coefficients ($C_{l,\max}$), and stall characteristics from linear to post-stall regimes.
* **Numerical vs. Experimental Comparison**: Discussion of discrepancies caused by panel method assumptions, 1D boundary layer modeling, transition location, and flow separation.

## Software & Methods
* **XFLR5**: Type 1 polar analysis combining panel methods with a 1D boundary layer model.
* **NACA TN-2502**: Benchmark experimental data source for validation.
